# Careerpilot

Project scaffold for a career assistant platform with frontend, backend, and AI services.

## Structure

- `frontend/`: React SPA with job search, tracking, chat, and resume upload.
- `backend-node/`: Express/Fastify API server for job orchestration and tracking.
- `services-python/`: FastAPI AI services for RAG, job agents, and chat assistant.

## Setup

1. Install frontend dependencies: `cd frontend && npm install`
2. Install backend dependencies: `cd backend-node && npm install`
3. Install Python dependencies: `cd services-python && pip install -r requirements.txt`

## Notes

This scaffold includes placeholder files and directories for future implementation.
